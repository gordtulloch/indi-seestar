ReleaseLog: 
Note! Features not supported in this demo do not imply lack of support in the alpaca Alpaca driver; updates will be released continuously. 
This demo is intended for secondary development reference only!

Overall
- Supports scanning and connecting to Camera, Focuser, Filter Wheel, and Telescope.
- Supports displaying connection status and parameter information for Camera, Focuser, Filter Wheel, and Telescope.

Camera
- Supports Gain and Exposure settings.
- Supports StartExposure and image display.

Focuser
- Supports Target position move.

Filter Wheel
- Supports Position Change (Dark, IR, LP).

Telescope
- Supports manual move.
- Supports Home.
- Supports setting tracking rate.
- Supports setting manual move rates for primary and secondary axes.
- Supports RA DEC Slew.
- Supports Alt Az Slew.
